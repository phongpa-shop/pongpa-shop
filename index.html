☁️ ซิงค์และสำรองอัตโนมัติ (Google Sheet)

รายการสินค้าและราคาต้นทุนเก็บใน Google Sheet ส่วนตัวของคุณ ไม่อยู่ในไฟล์เว็บ ทุกบิลและการแก้ไขสินค้าจะถูกส่งขึ้น Google Sheet ของคุณอัตโนมัติ ใช้ได้หลายเครื่องพร้อมกัน ถ้าไม่มีเน็ตจะเก็บในเครื่องก่อนแล้วส่งให้เองเมื่อออนไลน์

วิธีตั้งค่า (ทำครั้งเดียว ~5 นาที)
  1. สร้าง Google Sheet ใหม่ → เมนู ส่วนขยาย → Apps Script
  2. วางโค้ดจากไฟล์ Code.gs แทนของเดิม แล้วแก้ TOKEN เป็นรหัสที่ตั้งเอง
  3. กด ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป ตั้ง "เรียกใช้ในฐานะ: ฉัน" และ "ผู้มีสิทธิ์เข้าถึง: ทุกคน" แล้วคัดลอก URL
  4. ใน Apps Script เลือกฟังก์ชัน setupDailyBackup แล้วกดเรียกใช้ 1 ครั้ง (สำรองลง Drive ทุกวัน)
  5. วาง URL และรหัสลับด้านบน แล้วกด "บันทึกและเชื่อมต่อ"

สำรอง / ย้ายข้อมูล (ไฟล์)

ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้ (ฟรี ไม่ต้องมีเซิร์ฟเวอร์) ควรกดสำรองเป็นระยะ และใช้ไฟล์เดียวกันนำเข้าในเครื่องอื่นได้
